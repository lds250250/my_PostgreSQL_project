# 课程模板

> **这是给"要给我上课的人"的材料。规矩在 `如何教我.md` 里，这份只管"复制粘贴"。**
>
> **⚠️ 但别急着填 —— md 在这节课真正结束之后才写。**
> 讲的时候我们还在交流，路径、输出、报错都可能是猜的。等我说"这一课可以了"，再按讨论后的真实情况落文件。
> 规则见 `如何教我.md` 的 `7.8 md 什么时候写`。

---

## 怎么用

**课讲完、讨论完，把最下面那一整块复制出来，往里填。**

**四条规矩先记住：**

1. **六个环节可以加，不能减。**
   某一环节今天确实没有内容，也要写一行说明"为什么没有"，**不要默默删掉。**
2. **提交环节如果没有文件改动**，就写一句"今天没有文件改动，不提交"，**同样不要默默跳过。**
3. **一节课里不止一个概念**，就在每个环节内部用「一、」「二、」分开 ——
   不要拆成好几节课，也不要把六个环节重复好几遍。
4. **一节课只留一个核心能力**（见 `如何教我.md` 的 `4.1`）。有两个以上就该拆天。

**关于开头那块"本课的点"：**

它**不是第七个环节**，是六个环节之前的标牌 —— 来自 `如何教我.md` 的 `7.3`（每个点标出类别）。
先贴标牌，再进六环节。**重点 / 难点 / 普通点**三样都要有，没有就写"无"，说清为什么无。

**不在模板里的几样东西：**

| 不放进课里的 | 放哪 |
| --- | --- |
| 生词 | `速查/生词本/` 的分册（`PostgreSQL.md` / `PowerShell.md` / `SQL.md` …） |
| "留一个问题"、"讲师备注"、"环境限制"这类 | 属于对话，不属于课程档案 —— **不要写进 md** |
| 讲法技巧（打比方、用数字、反直觉） | 属于老师的手艺，见 `如何教我.md` 附录 B |

**最容易漏的三处，先点名：**

| 环节 | 最容易漏的 |
| --- | --- |
| 一 | **结尾那句"它是什么"** —— 少了它，后面的原理讲解是悬空的 |
| 三 | **让我先猜** —— 跳过猜测直接解密，这套方法就白设计了 |
| 六 | **能力总结**（`今天以后遇到什么问题，我可以独立判断`）—— 只写"学了什么"不算收尾 |

## 每一段具体怎么写

**空模板只管"有哪些格子"。每个格子该填成什么样，看 `如何教我.md`：**

| 环节 | 看哪里 |
| --- | --- |
| 一 | `3. 单课模板` · 各环节的要求 |
| 二 | `4.3 每节课必须有三类错误`、`5.3 工具箱要前置`、`6.4 不要假设环境永远正确` |
| 三 | `2.2 先实验后解释`、`4.4 实验后的保存点` |
| 四 | `5.1 命令要讲三层`、`2.3 培养判断能力` |
| 五 | `6.3 产出一张能复用的判断表` |
| 六 | `8.1 Git 提交`、`2.3 培养判断能力`、`9.3 用产出物验收` |

**讲法上想不出怎么写，翻 `附录 A：表达示例` 和 `附录 B：讲法技巧`。**
