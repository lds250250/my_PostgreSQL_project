# 生词本 · PostgreSQL

> **收什么**：PostgreSQL 这个软件自己的词 —— 命令、连接参数、`psql` 里的元命令、服务端配置文件。
> **不收**：SQL 语言本身的词（去 `SQL.md`）、PowerShell 的符号（去 `PowerShell.md`）。
> **规则**：见 `教学/如何教我.md` 的 `10.5 生词本`。

---

## 三个命令

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `psql` | 命令行客户端 | 在终端里连数据库、敲 SQL 的那个程序 |
| `initdb` | 初始化数据目录 | 把一片空文件夹变成一个能用的数据库 |
| `pg_ctl` | 服务控制 | 启动、停止、重启、查看数据库进程的那个命令 |

## `pg_ctl` 的四个动作

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `start` | 启动 | 把数据库进程跑起来 |
| `stop` | 停止 | 把数据库进程关掉 |
| `restart` | 重启 | 关掉再跑起来 |
| `status` | 看状态 | 问一句"服务器现在开着吗" |

## 连接参数（`psql` 和 `pg_ctl` 都用）

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `-U` | 用户 | 用哪个身份连进去 |
| `-h` | 主机 | 连哪台机器上的数据库 |
| `-d` | 数据库 | 连哪一个库 |
| `-p` | 端口 | 数据库在哪个端口上听 |
| `-D` | 数据目录 | 告诉 `pg_ctl`"数据库的数据在哪个文件夹" |
| `-l` | 日志文件 | 告诉 `pg_ctl`"运行日志写到哪个文件" |

## 输出格式参数（`psql` 专用）

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `-c` | 执行一条 | 执行完这条 SQL 就退出，不进交互界面 |
| `-t` | 只要值 | 输出里去掉表头和边框 |
| `-A` | 不对齐 | 输出用竖线分隔，方便程序读 |

## `psql` 里的元命令

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `\q` | 退出 | 从 `psql` 交互界面里退出来 |
| `\l` | 列出所有库 | 看这台服务器上有哪些数据库 |
| `\c` | 切换库 | 从当前库换到另一个库 |
| `\dt` | 列出所有表 | 看当前库里有哪些表 |
| `\d` | 看表结构 | 看某张表有哪些列、什么类型、什么约束 |
| `\?` | 查元命令帮助 | 忘了 `\` 开头的命令叫什么时查它 |
| `\h` | 查 SQL 帮助 | 忘了某条 SQL 的语法时查它 |
| `\x` | 竖排显示 | 一行太宽时，改成"字段名：值"竖着显示 |
| `\timing` | 显示耗时 | 每条 SQL 执行完，多打一行花了多少毫秒 |

## 服务端与配置

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `postgres` | 超级用户／默认库 | 我们建的那个用户名，同时也是默认数据库的名字 |
| `pgdata` | 数据目录（习惯叫法） | 我们给数据目录起的名字，不是关键字 |
| `postgresql.conf` | 主配置文件 | 数据库的设置都写在这里 |
| `pg_hba.conf` | 连接认证配置 | 谁能从哪台机器连进来，写在这里 |
| `server.log` | 服务日志 | 数据库运行时的报错和记录写在这里 |
| `port` | 端口号 | `postgresql.conf` 里的设置项，默认 5432 |
| `trust` | 免密认证 | 一种认证方式：不验密码就放行 |
| `#` | 注释符 | 配置文件里表示"这一行不生效" |
