## 我们自己定义的变量

这四个不是 PowerShell 自带的，是 `速查/PostgreSQL速查.md` 里 A 段定义的。

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `$PG` | 程序目录变量 | 指向 PostgreSQL 的 `bin` 文件夹 |
| `$DATA` | 数据目录变量 | 指向数据库数据所在的文件夹 |
| `$CONF` | 配置文件变量 | 指向 `postgresql.conf` |
| `$LOG` | 日志文件变量 | 指向 `server.log` |

## 运算符和符号

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `&` | 调用运算符 | 用来运行一个带引号的路径，比如 `& "$PG\psql.exe"` |
| `` ` `` | 续行符 | 表示"这一行还没完，下一行接着" |
| `$` | 取变量的值 | 写在名字前面，表示"我要的是这个变量里的东西" |
| `\|` | 管道 | 把前一条命令的输出，交给后一条命令处理 |
| `*>` | 重定向全部输出 | 把正常输出和错误都送到指定地方 |
| `$null` | 空 | 一个"什么都没有"的值，常用来丢弃输出 |

## 自动变量

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `$LASTEXITCODE` | 上条命令的退出码 | 0 一般表示成功，非 0 表示有情况 |

## 常用的 cmdlet

| 代码里的词 | 中文短名 | 一句话 |
| --- | --- | --- |
| `Get-Content` | 读文件 | 把文件内容读出来 |
| `-Tail` | 看末尾 | 只读最后几行，不刷屏 |
| `Set-Content` | 写文件 | 把内容写进一个文件 |
| `Get-ChildItem` | 列目录 | 列出文件夹里的东西 |
| `Test-Path` | 检查存在 | 问一句"这个文件或文件夹在不在" |
| `New-Item` | 新建 | 建文件或建文件夹，`-ItemType Directory` 就是建文件夹 |
| `Move-Item` | 移动／改名 | 把文件挪到另一个地方，或者改名字 |
| `Remove-Item` | 删除 | 删掉文件或文件夹 |
| `Select-Object` | 挑列 | 只要结果里的某几列，`-First` 只取前几条 |
| `Where-Object` | 筛行 | 按条件过滤结果 |
| `ForEach-Object` | 逐条处理 | 对结果里的每一条，都做一遍同样的事 |
| `Sort-Object` | 排序 | 把结果按某个字段排一下 |
