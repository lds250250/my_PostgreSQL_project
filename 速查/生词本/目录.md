# 生词本总目录

> **生词本是代码词典，不是知识笔记。** 这里按"词属于哪个东西"分成几本，各查各的。

| 分册 | 收什么词 | 文件 |
| --- | --- | --- |
| PostgreSQL | `psql` / `initdb` / `pg_ctl` / 连接参数 / `psql` 元命令 / 服务端配置文件 | `PostgreSQL.md` |
| SQL | SQL 语言本身的词：关键字、函数名、类型名 | `SQL.md` |
| PowerShell | `$PG` / `$LASTEXITCODE` / `Get-Content` 这类命令行工具和符号 | `PowerShell.md` |
| Python | `uv` / `psycopg` / 虚拟环境相关的词 | `Python.md`（Day 19 建） |
| Docker | 镜像、容器、卷相关的词 | `Docker.md`（第 15 周建） |

## 为什么分家

一本混装 40+ 个词、跨三个领域，查一个词要来回翻。
分开之后：写 SQL 时只翻 `SQL.md`，配环境时只翻 `PostgreSQL.md`。

## 规则

见 `教学/如何教我.md` 第三部分第 3 条。三条要点：

1. **第一次出现就记**，不要攒到周末补
2. **同一个词有新含义，再加一行**，不要覆盖
3. **每过几节课自己过一遍**；一眼看不懂的行，就把那行改写清楚

## 不进的

代码里没有的词（"死锁""幂等""三值逻辑"这类只在讲解里出现的概念）—— 讲课讲清就行。
